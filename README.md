# Application cheat sheets

Keyboard-shortcut references for CapCut on macOS and Windows, provided as HTML pages and Markdown files.

## Available references

| Platform | HTML | Markdown |
| --- | --- | --- |
| macOS | [Open file](capcut/capcut-shortcuts-cheat-sheet-mac.html) | [Read shortcuts](capcut/capcut-shortcuts-cheat-sheet-mac.md) |
| Windows | [Open file](capcut/capcut-shortcuts-cheat-sheet-windows.html) | [Read shortcuts](capcut/capcut-shortcuts-cheat-sheet-windows.md) |

There is also a [combined reference](capcut/shortcut-key-capcut.md).

## Use

Read the Markdown references on GitHub, or download the repository and open an HTML file in your browser. Shortcuts may differ by application version or custom key bindings; check them against your installed version of CapCut.

## Corrections

For an incorrect shortcut, include the platform, application version and the corrected key combination in an issue or pull request.
