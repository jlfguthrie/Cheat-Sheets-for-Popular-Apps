## 🌟 Features

> [!TIP]
> These cheat sheets are designed with modern web standards and responsive design principles

- **🎨 Beautiful Design** - Modern gradient backgrounds, cards with hover effects, and professional typography
- **📱 Fully Responsive** - Perfect on desktop, tablet, and mobile devices
- **🔍 Live Search** - Instant filtering of shortcuts as you type
- **⌨️ Platform Specific** - Native keyboard symbols for Mac (⌘⌥⇧) and Windows (Ctrl+Alt+Shift)
- **📄 Dual Format** - Both interactive HTML and clean Markdown versions
- **🚀 Fast Loading** - Optimized CSS and JavaScript for instant performance
- **🎯 Keyboard Navigation** - Use `Cmd/Ctrl + F` to focus search instantly

## 🤝 Contributing

We'd love your help expanding this collection! Here's how you can contribute:

### Adding New Cheat Sheets

1. **Fork** this repository
2. **Create** a new folder for your app: `mkdir your-app/`
3. **Generate** both HTML and Markdown versions
4. **Follow** the existing naming convention:
   - `your-app-shortcuts-cheat-sheet-mac.html`
   - `your-app-shortcuts-cheat-sheet-windows.html`
   - `your-app-shortcuts-cheat-sheet-mac.md`
   - `your-app-shortcuts-cheat-sheet-windows.md`
5. **Update** this README with your new cheat sheet
6. **Submit** a pull request

### Design Guidelines

> [!IMPORTANT]
> Please follow these guidelines for consistency:

- Use the same **color scheme** (blue gradients: `#4facfe` to `#00f2fe`)
- Include **version numbers** and **author attribution**
- Implement **responsive design** with mobile breakpoints
- Add **search functionality** to HTML versions
- Use **native keyboard symbols** for each platform
- Organize shortcuts into **logical categories**
