### Key Symbols Legend

- `⌘` = Command (Cmd)
- `⌥` = Option (Alt)
- `⇧` = Shift
- `Space` = Spacebar
- `←→↑↓` = Arrow Keys

### Quick Tips

- Use `⌘F` to search shortcuts in the HTML version
- Most editing shortcuts work across all timeline tracks
- Combine with other modifiers for advanced functionality
