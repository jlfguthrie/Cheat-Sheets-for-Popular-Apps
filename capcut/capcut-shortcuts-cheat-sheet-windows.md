_Quick Reference Cheat Sheet_

## 🎬 Editing & Timeline

| Action                   | Shortcut           |
| ------------------------ | ------------------ |
| Split Clip               | `Ctrl + B`         |
| Split All Tracks         | `Ctrl + Shift + B` |
| Select Mode              | `A`                |
| Split Mode               | `B`                |
| Select to Left           | `[`                |
| Select to Right          | `]`                |
| Activate/Deactivate Clip | `V`                |

## 🎮 Navigation & Playback

| Action                   | Shortcut    |
| ------------------------ | ----------- |
| Play                     | `Space`     |
| Previous Frame           | `←`         |
| Next Frame               | `→`         |
| Step Back Many Frames    | `Shift + ←` |
| Step Forward Many Frames | `Shift + →` |
| Locate to First Frame    | `Home`      |
| Locate to Last Frame     | `End`       |
| Shuttle Left             | `J`         |
| Shuttle Stop             | `K`         |
| Shuttle Right            | `L`         |

### Key Symbols Legend

- `Ctrl` = Control Key
- `Alt` = Alt Key
- `Shift` = Shift Key
- `Space` = Spacebar
- `←→↑↓` = Arrow Keys

### Quick Tips

- Use `Ctrl + F` to search shortcuts in the HTML version
- Most editing shortcuts work across all timeline tracks
- Combine with other modifiers for advanced functionality
